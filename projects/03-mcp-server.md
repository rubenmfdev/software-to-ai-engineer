# Project 3 · MCP server

**Phase:** 6
**Status:** not started

## Goal

A Model Context Protocol server that exposes a real, useful API to AI assistants, built with the security and testing a customer would expect.

## Scope

- Tools, resources and prompts for one well-defined domain (for example a public flight-status or transport API)
- Authentication, input validation, and protection against prompt injection through tool output
- Tests, plus an example client session
- Optionally, connect it to Project 1's agent

- [ ] Public repo with install instructions for an MCP client
- [ ] Security notes: what the server can do, and what it refuses
